# ShopProject — учебный интернет-магазин

## Описание

Учебный проект по дисциплине «Фронтенд и бэкенд разработка»: сайт интернет-магазина для просмотра товаров и оформления заявок.

В текущей версии реализована главная страница с описанием проекта, преимуществами, карточками товаров и модальным окном заявки. Обработка формы выполняется в браузере; отправка данных на сервер пока не подключена.

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

Цель работы — разработать многостраничный HTML/CSS-сайт интернет-магазина с семантической разметкой, внешним CSS-файлом, общей навигацией и единым оформлением страниц. Обязательные страницы и состояние их реализации описаны ниже.

## Структура проекта

```text
kr1-html-css-shop/
├── index.html       # Главная страница и модальное окно заявки
├── css/
│   └── style.css    # Оформление страницы, меню, карточек и формы
├── js/
│   └── main.js      # Работа модального окна и проверка формы
├── images/         # Папка для изображений (пока пустая)
├── .gitignore      # Список файлов, исключённых из Git
└── README.md       # Описание проекта и инструкция по просмотру
```

Пустая папка `images/` не сохраняется в Git и может отсутствовать после скачивания репозитория.

## Используемые технологии

- HTML5 — семантическая разметка, форма и элемент `dialog`;
- CSS3 — оформление, CSS-переменные, Flexbox и Grid;
- БЭМ — именование классов меню и карточек товаров;
- JavaScript — открытие и закрытие модального окна, выбор товара и проверка формы;
- Git и GitHub — контроль версий и хранение исходного кода;
- GitHub Pages — публикация сайта.

## Инструкция по просмотру проекта

### На GitHub Pages

1. Перейдите по ссылке на опубликованный проект выше.
2. Используйте меню или кнопку «Перейти к товарам» для перехода к разделам главной страницы.
3. Нажмите «Заказать» в карточке товара, чтобы открыть форму заявки.
4. Заполните обязательные поля: имя (не менее двух символов), e-mail, телефон в формате `+7 (900) 000-00-00`, тему заявки и согласие на обработку данных.
5. Нажмите «Отправить заявку». При корректном заполнении появится сообщение об успешной отправке. Это учебная демонстрация: данные на сервер не отправляются.

### Локально

1. Откройте [репозиторий проекта](https://github.com/M1qght/kr1-html-css-shop) и скачайте архив через **Code → Download ZIP** либо клонируйте репозиторий:

   ```bash
   git clone https://github.com/M1qght/kr1-html-css-shop.git
   ```

2. Если скачан архив, распакуйте его.
3. Откройте файл `index.html` в современном браузере, сохранив расположение папок `css` и `js` рядом с ним.

Установка зависимостей и сборка не требуются.

| Страница | Назначение и содержимое | Текущее состояние |
| --- | --- | --- |
| Главная | Знакомство с магазином, преимущества, популярные товары и навигация. | Реализована в `index.html`. |

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`.

## Реализованные элементы интерфейса

- кнопки заказа в карточках товаров;
- модальное окно с формой заявки;
- поля формы: имя, e-mail, телефон, дата, тема, комментарий, согласие;
- базовая HTML-валидация;
- базовая JS-обработка формы;
- сообщение об успешной отправке.

## Самостоятельные доработки

- Горизонтальное меню на Flexbox: пункты располагаются в ряд и переносятся при нехватке ширины.
- Адаптивная сетка товаров на Grid: на широком экране три карточки стоят рядом, на узком число колонок уменьшается.
- БЭМ-классы для элементов меню и карточек: `site-nav__item`, `site-nav__link`, `product-card__title`, `product-card__description`, `product-card__price` и `product-card__button`.
- Выравнивание кнопок заказа по нижнему краю карточек с помощью Flexbox.
- Исправление выбора товара: кнопки второй и третьей карточек передают в форму соответствующие названия через `data-product`.
